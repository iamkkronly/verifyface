## এটা কী?

`verifyface` একটি Python লাইব্রেরি, যা দিয়ে **মুখ দেখে মানুষ চেনা ও যাচাই** করা যায়।
একবার একটি ছবি দিয়ে নিবন্ধন (enroll) করলে, পরে **অন্য পোশাক, অন্য জায়গা, অন্য আলো,
এমনকি কয়েক বছর পরের ছবি দিয়েও** সেই মানুষকে চেনা যাবে।

বিশেষ সুবিধা:

* **ইন্টারনেট লাগে না** — মুখ চেনার মডেল দুইটিই লাইব্রেরির ভেতরে দেওয়া আছে।
* **কোনো GPU লাগে না** — সাধারণ ল্যাপটপ বা রাস্পবেরি পাই-তেও চলে।
* **ছবি কোথাও যায় না** — সব কাজ আপনার কম্পিউটারেই হয়।
* **ছবি সংরক্ষণ হয় না** — শুধু ১২৮টি সংখ্যার একটি "টেমপ্লেট" জমা থাকে।
* **ছবি কখনো নষ্ট হয় না** — ইনপুট ছবি শুধু পড়া হয়, কখনো লেখা হয় না।

```bash
pip install verifyface
```

```bash
verifyface doctor
```

শেষে `everything looks good` দেখলে সব ঠিক।

## ২. প্রথম নিবন্ধন

একটি স্পষ্ট ছবি দিয়ে:

```bash
verifyface enroll kaustav amar_chobi.jpg
```

Python-এ:

```python
import verifyface as vf

result = vf.enroll("kaustav", "amar_chobi.jpg")
print(result.explain())
```

> **ভালো ছবি কেমন হবে?**
> মুখটা ছবির মধ্যে অন্তত ৮০ × ৮০ পিক্সেল, ক্যামেরার দিকে তাকানো, স্বাভাবিক আলো,
> এবং ছবিতে **একজনই** মানুষ।

দুই-তিনটি ছবি দিলে ফলাফল আরও ভালো হয়:

```bash
verifyface enroll kaustav chobi_2021.jpg aajker_chobi.jpg chosma_pore.jpg
```

## ৩. যাচাই (verify)

```bash
verifyface verify kaustav notun_selfie.jpg
```

* ফল `0` → একই মানুষ
* ফল `1` → অন্য মানুষ
* ফল `2` → কোনো সমস্যা (ছবি নেই, মুখ পাওয়া যায়নি …)

Python-এ:

```python
r = vf.verify("kaustav", "notun_selfie.jpg")
if r:
    print(f"স্বাগতম! আত্মবিশ্বাস {r.confidence:.0%}")
else:
    print(f"মেলেনি (score {r.score:.2f})")
```

আপনি চাইলে শুধু দুটি ছবি তুলনাও করতে পারেন — কিছুই সংরক্ষণ হবে না:

```python
vf.compare("purono.jpg", "notun.jpg").explain()
```

## ৫. লাইভ ক্যামেরা যাচাই

এখানে একটা গুরুত্বপূর্ণ ব্যাপার আছে — **প্রিন্ট করা ছবি বা মোবাইলের ভিডিও দিয়ে**
যাতে প্রতারণা না করা যায়, তাই ক্যামেরা চালু হলে দুইটি **এলোমেলো কাজ** করতে বলা হয়:
মাথা বাঁ দিকে ঘোরানো, মাথা নাড়ানো, কাছে আসা বা চোখ পিটপিট করা। মৃত ছবি মাথা
ঘোরাতে পারে না, তাই ধরা পড়ে যায়।

```bash
verifyface demo          # ক্যামেরা খুলে পরীক্ষা করুন
```

```python
import verifyface as vf

result = vf.scan_live("kaustav")     # pip install "verifyface[camera]" লাগবে
print(result.passed, result.liveness.explain())
```

সার্ভারে ক্যামেরা না থাকলে (যেমন ওয়েবসাইট), ব্রাউজার থেকে ফ্রেম পাঠানো যায়:

```python
session = vf.LiveSession(identity="kaustav")
state = session.begin()
while state["status"] != "done":
    state = session.feed(frame_bytes)     # ব্রাউজার থেকে আসা ছবি
    print(state["prompt"])                # "Turn your head slowly to your left"
print(state["passed"])
```

## ৬. ব্রাউজার অ্যাপ (কোড না জেনেও ব্যবহার)

```bash
verifyface serve
```

তারপর ব্রাউজারে <http://localhost:8000> খুলুন। তিনটি ট্যাব:

1. **লাইভ স্ক্যান** — ক্যামেরা দিয়ে যাচাই
2. **ছবি যাচাই** — ছবি আপলোড করে যাচাই
3. **নিবন্ধন** — নতুন মানুষ যোগ করা

পুরো অ্যাপ **ইংরেজি ও বাংলা** দুই ভাষাতেই আছে (উপরের ডান দিকে ভাষা বদলান)।
আলাদা করে Flask বা Node ইনস্টল করতে হয় না — Python-এর স্ট্যান্ডার্ড লাইব্রেরিতেই
সার্ভার চলে।

## ৭. নিজের প্রজেক্টে যোগ করা

```python
import verifyface as vf

# প্রোফাইল প্রজেক্টের ফোল্ডারে রাখুন
verifier = vf.Verifier(vault="data/faces", threshold="strict")

def login(username: str, photo_path: str) -> bool:
    if not verifier.enrolled(username):
        return False
    return bool(verifier.verify(username, photo_path))
```

FastAPI / Flask / Django / Streamlit / Gradio — সবগুলোতে এক লাইনে যোগ করা যায়।
দেখুন [integrations.md](integrations.md)।

## ৮. কোথায় তথ্য জমা থাকে?

| অপারেটিং সিস্টেম | ফোল্ডার |
|---|---|
| Linux | `~/.verifyface/vault` |
| macOS | `~/Library/Application Support/verifyface/vault` |
| Windows | `%APPDATA%\verifyface\vault` |

প্রতিটি মানুষের জন্য একটি ছোট ফাইল (প্রায় ২ KB), সাথে একটি ব্যাকআপ কপি
(`.bak`)। **কোনো ছবি জমা থাকে না**, শুধু ১২৮টি দশমিক সংখ্যা।

পাশে `key.bin` নামে একটি চাবি থাকে (অনুমতি `0600` — শুধু আপনি পড়তে পারবেন)।
ফাইলগুলো AES-256-GCM দিয়ে এনক্রিপ্ট করা যায়:

```bash
pip install "verifyface[secure]"
```

## ৯. "মুখ নষ্ট হবে না" — কীভাবে নিশ্চিত করা হয়েছে?

| স্তর | নিশ্চয়তা |
|---|---|
| **শুধু পড়া** | ছবি ফাইল সবসময় read-only ভাবে খোলা হয়; আপনার numpy অ্যারে কপি করে কাজ হয়। আপনার ছবি কখনো বদলায় না। |
| **স্বাক্ষর** | প্রতিটি টেমপ্লেটে HMAC-SHA256 স্বাক্ষর থাকে। একটি বিট বদলালেই ধরা পড়ে। |
| **পরমাণু-নিরাপদ লেখা** | অস্থায়ী ফাইলে লিখে তারপর নামান্তর — বিদ্যুৎ চলে গেলেও অর্ধেক ফাইল তৈরি হয় না। |
| **স্বয়ং-মেরামত** | ভালো ব্যাকআপ থেকে নিজে থেকেই ঠিক হয়ে যায়, ফলে কেউ চিরকালের জন্য বন্ধ হয়ে যায় না। |

## ১২. সাধারণ সমস্যা

**"NoFaceFoundError"** — মুখ পাওয়া যায়নি। মুখ বড় করুন (অন্তত ৬৪ পিক্সেল),
আলো বাড়ান, সোজা তাকান।

**"The face is too small"** — ক্যামেরার কাছে আসুন বা বড় ছবি ব্যবহার করুন।

**"TemplateCorruptedError"** — টেমপ্লেট নষ্ট। সাধারণত ব্যাকআপ থেকে নিজেই ঠিক হয়ে যায়;
না হলে আবার enroll করুন (`verifyface delete name` তারপর `verifyface enroll name photo.jpg`)।

**ক্যামেরা খুলছে না** — অন্য অ্যাপ (Zoom, Teams) বন্ধ করুন, অথবা
`vf.scan_live("name", camera=1)` দিয়ে অন্য ক্যামেরা চেষ্টা করুন।

## ১২.১ যমজ (twins) ও হুবহু দেখতে একই রকম মানুষ — সবচেয়ে বড় সীমাবদ্ধতা

স্বাধীনভাবে পরীক্ষা করে দেখা গেছে ১.০.১ সংস্করণে **যমজ ভাই-বোনকে আলাদা করতে
পারে না** (স্কোর ০.৫৪ ও ০.৭৯ — দুটোই ভুলভাবে পাস)। ১২৮ সংখ্যার ফেস-এমবেডিং দিয়ে
এটি আলাদা করা আসলে সম্ভব নয়।

১.১.০ সংস্করণে এর জন্য তিনটি ব্যবস্থা যোগ করা হয়েছে:

```python
v = vf.Verifier(profile="high_security")     # কঠোর + লাইভনেস

v.enroll("twin_a", "a.jpg")
v.enroll("twin_b", "b.jpg")
print(v.lookalikes())        # [('twin_a', 'twin_b', 0.79)] — নিজে থেকেই ধরা পড়ে

v.set_pin("twin_a", "1111")  # দ্বিতীয় স্তর (PIN)
v.set_pin("twin_b", "2222")

v.verify("twin_a", probe)                   # False — শুধু মুখ দিয়ে ঢোকা যাবে না
v.verify("twin_a", probe, pin="1111")       # True  — মুখ + PIN
v.verify("twin_a", probe, pin="2222")       # False — অন্য যমজের PIN
```

* **lookalike detection** — কারা একই রকম দেখতে, তা বলে দেয় (`verifyface lookalikes`)
* **ambiguity guard** — অন্য কোনো নিবন্ধিত ব্যক্তির স্কোর খুব কাছাকাছি হলে যাচাই
  স্বয়ংক্রিয়ভাবে বাতিল হয়
* **PIN (দ্বিতীয় স্তর)** — শুধু মুখ দিয়ে কখনো পাস হবে না

> সংক্ষেপে: **শুধু মুখ → যমজের জন্য যথেষ্ট নয়। মুখ + PIN → হ্যাঁ।**

## ১২.২ ছবির ছবি দেখিয়ে প্রতারণা

আপলোড করা ছবি কখনোই প্রমাণ করে না মানুষটি সামনে উপস্থিত। ১.১.০ থেকে:

```python
vf.verify("kaustav", "chobi.jpg", liveness="auto")      # স্ক্রিন/প্রিন্ট বাতিল
vf.verify("kaustav", "chobi.jpg", liveness="required")  # ব্যর্থ হলে ত্রুটি
```

এছাড়া নিবন্ধিত ছবির হুবহু কপি দিলে `replayed_sample=True` রিপোর্ট হয়, এবং
`high_security` প্রোফাইলে তা সরাসরি বাতিল হয়। আসল লগইনের জন্য সবসময়
**লাইভ স্ক্যান** ব্যবহার করুন।

## ১৩. সৎ সীমাবদ্ধতা

* এটি একটি **সুবিধাজনক দ্বিতীয় স্তর**, ব্যাংকের নিরাপত্তার বিকল্প নয়।
* ৩D মাস্ক বা ডিপফেক ভিডিও আটকানো এই সিস্টেমের ক্ষমতার বাইরে।
* যমজ ভাই-বোন চেনা সবচেয়ে কঠিন — এখন ambiguity guard + PIN দিয়ে সামলানো যায়,
  কিন্তু শুধু মুখ দিয়ে নয়।
* খুব বড় রোদ-চশমা বা ফেস মাস্ক ব্যবহারে নির্ভুলতা কমে।
